# Значки ачивок: план загрузки

Всего 81 значков, по 5 в день бесплатно: 17 дней. Сначала первые тиры всех 25 ачивок (дни 1-5): их получает больше всего игроков, потом вторые тиры, третьи и четвёртые.

Картинки лежат в `assets/badges/images/`. Как загрузить один значок:

1. create.roblox.com → Creations → вверху переключиться на группу **sad mansion studios**.
2. Открыть игру → **Engagement → Badges → Create Badge**.
3. Загрузить картинку из столбца «Файл», вставить «Название» и «Описание» как есть, Enabled оставить включённым, Create.
4. В списке Badges у значка **⋯ → Copy Asset ID**.

Id присылай подряд, без подписей: я сам прочитаю название каждого значка на Roblox и разложу их по тирам. Лимит 5 в сутки считается по GMT (у нас сутки начинаются в 03:00 по Москве).
