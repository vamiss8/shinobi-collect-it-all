# Совместный тест: план

Shinobi: Collect It All! · для владельца и соавтора · 08.10.2026

Правила Roblox в 2026 году менялись несколько раз. Всё ниже сверено с официальной документацией
и форумом разработчиков на 08.10.2026, но сам я эти шаги не проходил: первый же отказ на любом
шаге — повод остановиться и сверить с разделом «Если не получилось».

## Что изменилось по сравнению с прежней инструкцией

- **Team Create в России отключён** примерно с 17 июня 2026, независимо от проверки возраста.
  Вместе править место в Studio нельзя. Официального комментария Roblox нет.
- **Публичная игра тоже требует проверки возраста** у владельца (с 19 мая 2026). Прежняя
  инструкция предлагала публичную игру как способ обойтись без проверки: это уже не так.
- **Проверку возраста в России пройти можно**, по отзывам на форуме она работает.
- **Публичной игру делать не нужно.** Есть режим Limited: игра видна только тестировщикам или
  друзьям владельца и не попадает в поиск. Для нас это важно ещё и из-за имён персонажей.
- **Галочка Enable Studio Access to API Services не нужна.** Сохранения на живом сервере
  работают и без неё. Она открывает настоящие сохранения тестам в Studio, и тогда пробный
  запуск в Studio будет портить прогресс живого теста.

## Как это устроено у нас

Соавтор в Roblox проекту не нужен. Весь мир и вся логика собираются из кода в `src/`, поэтому:

- **код** вы делите через git (приватный репозиторий на GitHub, соавтор в нём collaborator);
- **каждый** запускает игру у себя в Studio через `rojo serve` и тестирует в одиночку;
- **общий сервер** живёт на одном аккаунте. Публикует тот, чей аккаунт владеет игрой.

## Шаг 1. Оба: проверка возраста и дружба

1. В приложении Roblox: Settings → Account Info → проверка возраста (селфи-видео или документ).
   Владельцу она нужна, чтобы открыть игру другим. Соавтору — чтобы его в игру пустило: новая
   игра доступна проверенным игрокам 16+.
2. Добавьте друг друга в друзья в Roblox.
3. Узнайте свои ID: число в адресе профиля `roblox.com/users/123456789/profile`.

## Шаг 2. Владелец: подготовить код

Уже сделано в проекте:

- `src/server/PlaytestGate.luau` — белый список. Пока список пуст, он выключен.
- Сохранения теста пишутся в отдельное хранилище `Playtest1` (`src/server/Data.luau`).
  Релиз начнёт всех с нуля, а прогресс теста сбрасывается сменой цифры.

Осталось вписать два ID в `PlaytestGate.luau`:

```lua
local ALLOWED: { number } = {
	123456789, -- owner
	987654321, -- co-author
}
```

И проверить:

```bash
powershell -File scripts/check.ps1
```

## Шаг 3. Владелец: опубликовать

1. Открыть место в Studio, запустить `rojo serve`, нажать Connect и дождаться синхронизации.
2. File → Publish to Roblox, создать новую игру. Она появится приватной.
3. Выставить Max Players = 6 в настройках стартового места (в Studio: Game Settings → Places).
   В игре шесть додзё, седьмого игрока сервер выкинет.
4. Открыть create.roblox.com/dashboard/creations и выбрать игру.
5. Заполнить опросник Content Maturity & Compliance.
6. Configure → Settings → Audience → **Limited → Friends**. Сохранить.
7. Скопировать ссылку на страницу игры и отправить соавтору.

Вариант строже: Audience → **Limited → Playtesters**, а соавтору в Studio через кнопку
Collaborate выдать право **Play**. Тогда в игру попадают только названные люди, а не все друзья.
Какой из двух вариантов пускает российский аккаунт, покажет проба: начните с Friends.

## Шаг 4. Оба: зайти вместе

1. Владелец заходит через обычное приложение Roblox, не через Studio.
2. Соавтор открывает ссылку и жмёт Play. Если попал на другой сервер, выйти и зайти через
   профиль владельца кнопкой Join.
3. Чат в игре для российских аккаунтов отключён самим Roblox. Голос и текст — в Discord
   или Telegram.

## Шаг 5. Что проверять вдвоём

Этого в одиночку не увидеть:

- У каждого своё додзё, табличка с именем, появление у своего входа.
- Оба бросают с одной полосы одновременно: шкалы, полёты и рулетки не мешают друг другу.
- Кунай второго игрока виден в полёте, его враг и погоня тоже. Рулетку видит только бросавший.
- Нажатие кнопки прокачки в чужом додзё даёт «This is not your dojo» и ничего не покупает.
- Лавки рынка работают у обоих сразу.
- Один выходит: его додзё пустеет, шиноби и доски с кнопками исчезают. Заходит снова: всё на месте.
- Сохранения: выйти обоим, зайти через пару минут. Рё, Chakra, шиноби и кунай на месте,
  пришло сообщение о доходе за время отсутствия.
- Белый список: зайти третьим аккаунтом, если он есть. Его должно выкинуть.

Ошибки сервера видны владельцу прямо в игре: F9 → вкладка Server.

## Когда код обновился

1. Автор правки запускает `check.ps1` и отправляет изменения в git.
2. Владелец забирает их, синхронизирует через Rojo и делает File → Publish to Roblox.
3. Оба выходят из игры и заходят снова: пустой сервер закрывается, новый поднимается уже
   с новой версией. Либо в Creator Hub у игры: Restart Servers с опцией
   «Restart only servers with outdated versions».

## Если не получилось

| Что видно | Что делать |
| --- | --- |
| Audience не сохраняется, просит проверку возраста | Владелец не прошёл проверку или аккаунту меньше 2 дней |
| Audience не сохраняется, просит опросник | Заполнить Content Maturity & Compliance |
| Соавтор не может нажать Play | Он не прошёл проверку возраста, ему меньше 16 или вы не друзья |
| Выкинуло с «closed testing» | Неверный ID в `PlaytestGate.luau`: исправить и опубликовать заново |
| Limited → Friends не пускает, а Playtesters тоже | Запасной путь: Audience → Public. Белый список уже стоит, чужих выкинет |
| Старая версия игры | Владелец не опубликовал или вы не перезашли |

Запасной путь через Public работает, но страница игры становится видна всем. Название у нас
нейтральное, а описание и иконку на время теста лучше оставить пустыми.

## Перед настоящим релизом

- Очистить список в `PlaytestGate.luau`. Иначе в игру никто, кроме вас, не зайдёт.
- В `src/server/Data.luau` сменить хранилище с `Playtest1` на `PlayerData`.
